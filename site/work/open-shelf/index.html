OPEN SHELF / SAMPLE CONCEPT

01 / OVERVIEW

A starting point for possibility.

This sample provides a starting structure for a future reading-related case study. It is not completed work or a claim of user research.

02 / THE QUESTION

How might a reading interface invite discovery without overwhelming the reader?

A framing question to explore, rather than a finding from research.

03 / EXPLORATION

Questions before answers.

These are proposed areas for investigation. They have not been tested or validated.

  1. What information would help someone explore a book?
  2. How could browsing feel more personal?
  3. Which interface details would need usability testing?

A proposed direction uses editorial typography, a small set of categories, and a flexible reading collection. These choices have not been validated.
