01 / OVERVIEW

A starting point for possibility.

This sample is a visual exploration created for the portfolio infrastructure. It is not presented as Emily’s submitted artwork or a commissioned identity.

02 / THE QUESTION

How can the same composition express a different visual mood?

A framing question to explore, rather than a finding from research.

03 / EXPLORATION

Questions before answers.

These are proposed areas for investigation. They have not been tested or validated.

  1. How does scale change the relationship between words and shapes?
  2. What happens when a palette changes but the layout stays the same?
  3. Where can expressive typography still remain readable?

The proposed visual system pairs a large serif treatment with a circle, an asterisk, and a restrained palette. Repeated elements make it possible to compare variations without changing everything at once.
